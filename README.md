# CN BIOLUX – Logos

Logos de **CN BIOLUX – Energías Renovables**, separados por variante y por elemento (logo completo, icono y texto).

## Estructura

| Carpeta | Descripción |
|---|---|
| `01_circulo_sol_panel` | Sol y panel solar dentro de una hoja circular, con el nombre a la derecha |
| `02_app_casa_solar` | Icono tipo app: casa con paneles solares y hoja |
| `03_hoja_rayo` | Hoja con rayo, con curva verde inferior |
| `04_circulo_rayo` | Rayo dentro de un círculo verde y azul, con curva verde inferior |
| `05_panel_solar_horizontal` | Panel solar y sol sobre el nombre (versión horizontal) |
| `06_sello_circular` | Sello circular con el nombre en el borde |
| `07_hoja_simple` | Hoja simple con el nombre a la derecha y curva verde inferior |

## Archivos dentro de cada carpeta

- `logo_completo.png`: logo entero.
- `icono*.png`: solo el símbolo.
- `texto.png`: "CN BIOLUX" y "Energías Renovables".
- `curva_verde.png`: trazo verde inferior (solo en 03, 04 y 07).
- Cada archivo tiene una versión `*_fondo_blanco.png` con fondo blanco sólido.

## Uso

- Los PNG sin sufijo tienen **fondo transparente**, pensados para fondos claros.
- Sobre fondos oscuros, el texto azul marino pierde contraste: conviene una versión en blanco.
- Los archivos están ampliados 4x desde la imagen original. Para impresión en gran formato se recomienda una versión vectorial (SVG).
